# 리센느, 지금

쇼츠로 세어 본 리센느의 숫자를 한 장에 모은 페이지. 단일 HTML 이 `data/*.json` 을 읽어 그린다.

**화면은 채널 두 개로 나뉜다.** 머리 밑의 전환 단추가 RESCENE 공식 채널과 안원잘부를 바꾼다.
채널마다 「01 지금 이 순간 · 02 채널 고유 화면 · 03 영상 랭킹」이 딸리고
(RESCENE 에는 「04 라이브 아카이브」, 안원잘부에는 「04 카카오 이모티콘」이 더 있다),
그 아래 「두 채널 공통」 구역(트렌드·브랜드평판·100만 클럽·검색어·아카이브·출처)은 늘 같이 보인다.
`#rescene` · `#anwonjalbu` 로 채널을 지정해 링크할 수 있다.

**<https://viztabviz-lab.github.io/rescene-now/>**

## 열어 보기

`index.html` 을 파일로 직접 열면 브라우저가 `data/*.json` 읽기를 막는다. 서버로 띄운다.

```
python -m http.server 8000
```

→ http://localhost:8000

## 세 나라말 (한국어 · English · 日本語)

머리 오른쪽 단추로 고른다. 고른 값은 `localStorage` 에 남고, 주소로도 열 수 있다.

```
?lang=en      영어
?lang=jp      일본어   (ja · JP · ja-JP 도 같이 받는다)
?lang=kr      한국어   (ko 도 받는다)
```

**사람이 적는 코드는 제각각이라 다 받아 준다.** `코드정리()` 가 `jp→ja` · `kr→ko` 로 맞춘다.
안쪽에서 쓰는 값은 표준 코드(`ko` · `en` · `ja`)로 고정한다 — `<html lang>` 이 그 값을
그대로 받으므로 스크린리더와 검색엔진이 읽는 것도 이 값이다.

처음 들어온 사람은 브라우저 언어를 따른다(일본어면 일본어, 한국어면 한국어, 나머지는 영어).

**옮기는 것과 안 옮기는 것을 나눈다.**

| | 어떻게 |
|---|---|
| 화면 껍데기 · 제목 · 설명글 | **옮긴다.** `lang.js` 의 `STR` |
| 사람·그룹 이름 | **표기만 바꾼다.** `이름표` (원이→Wony→ウォニ) |
| 형식·요일·연령 탭 같은 낱말 | **옮긴다.** `낱말` |
| 영상 제목 · 검색어 · 이모티콘 문구 · 쇼츠 카드 제목 | **그대로 둔다.** 실제 한국어 원문이라 옮기면 없는 자료를 지어내는 것이 된다. 대신 목록 밑에 「원문 그대로」 단서(`.raw`)가 뜬다 |
| JSON 안에 든 방법론 설명글 | 한국어는 원문, 나머지는 `tj()` 로 사전에서 꺼낸다 |

**큰 수는 나라말마다 자리 이름이 다르다** — `만()` 이 갈라 쓴다.

```
1,070,000  →  107만 / 1.07M / 107万
433,789,079 → 4억 3,379만 / 433.8M / 4億 3,379万
```

### 문구를 고칠 때

`lang.js` 만 고치면 된다. 값이 들어가는 문장은 함수이고 **인자 순서가 세 나라말에서 같아야 한다.**

```js
"s4.sub": {ko:(n,t,c,p)=>`본편 ${n}편 누적 ${t}. …`,
           en:(n,t,c,p)=>`${n} main videos, ${t} views in total. …`,
           ja:(n,t,c,p)=>`本編 ${n}本で累計 ${t}。…`},
```

없는 열쇠·없는 나라말은 **한국어로 떨어진다.** 빠뜨려도 화면이 비지 않는다.

### 건드리면 안 되는 한국어

`data-ch="안원잘부"` · `data-v="조회수"` · `상태.채널==="리센느"` · `x.형식==="쇼츠"` 처럼
**식별자로 쓰이는 한국어**가 있다. 화면 글자는 `data-word` 나 `낱()` 이 따로 입힌다 —
값은 한국어 그대로 두고 보이는 글자만 바꾼다.

## 아카이브(화면 08)가 채워지는 법

`daily` 가 돌 때마다 `@data-viz` 채널(`UCXhPSo-zn2vM_sMzDwM9_tw`)의 최근 40편을 훑어
`archive.json` 에 없는 편을 카드로 붙인다. 손댈 곳은 세 상수뿐이다.

- **`아카이브시작 = "2026-08-09"`** — 리센느 소재로 돌린 날. 그 전 편(야구·선거)은 이 페이지와 무관하다.
- **`아카이브관련어`** — 제목이나 설명에 이 중 하나가 있어야 카드가 된다. 같은 채널에 올라오는
  연휴·광복절·서울 인구·토스API 편을 거르는 장치다. **「메이」는 넣지 않는다 — 「메이저리그」에 걸린다.**
  그 편들은 설명에 「안원잘부」가 들어 있어 어차피 걸린다.
- **`첫문장()`** — 새 카드의 「주장」은 영상 설명의 **첫 문장**이다. 첫 「줄」을 쓰면 안 된다.
  유튜브 설명은 한 문장이 두세 줄로 접혀 있어 「…8월 19일까지」처럼 중간에서 끊긴다.

**이미 있는 카드는 다시 쓰지 않는다.** 「주장」과 「수치」는 사람이 쓴 문장이라 유튜브에서
되받을 수 있는 값이 아니다. 자동으로 실린 카드는 **수치가 비어 있고, 화면은 빈 수치 줄을 그리지 않는다** —
나중에 손으로 채워 넣으면 그대로 남는다.

규칙을 고쳤으면 카드가 빠지지 않는지 먼저 확인한다. 이미 실린 카드가 규칙에 걸러지면
그 편은 다음 수집에서 화면에서 사라진 것처럼 보인다(실제로는 그대로 남지만, 새 편이 안 붙는다).

## 카카오 이모티콘 순위(화면 04, 안원잘부)

인기 순위는 **로그인 없이 API 로 받는다.** `daily` 가 돌 때마다 여섯 탭을 다시 잰다.

```
GET https://e.kakao.com/api/items/hot?ageBand={TEENS|TWENTIES|THIRTIES|FORTIES|FIFTIES_PLUS}&miniOnly=false&page=0&size=50
    ageBand 를 빼면 전체 탭 · size 최대 50
GET https://e.kakao.com/api/items/{slug}     상세 — hero.price 에 정가·할인율
헤더: Referer: https://e.kakao.com/
```

- **페이지 HTML 을 긁으면 안 된다** — 4KB 짜리 SPA 껍데기라 데이터가 하나도 없다.
  이 주소는 번들 `assets/popular-*.js` 안에 있고 번들 이름은 배포마다 바뀐다.
- **순위는 실시간으로 바뀐다.** 그래서 화면에 「전 탭 1위」를 적어 두지 않고 받아 온 값으로
  문장을 만든다 — 2위로 내려가면 화면도 2위라고 말한다. 잰 시각을 분 단위로 같이 적는다.
- **24종이 어느 편에서 나왔는지는 수집기가 건드리지 않는다.** 사람이 프레임을 눈으로 대조해
  확정한 값이다. 카카오가 자막을 다시 쓴 것이 있어(「마떼루용~」의 원본 자막은 「기다린다구~」)
  대사 검색으로는 찾을 수 없고 프레임이 최종 근거다.
- 이모티콘 이미지는 저장소에 두지 않는다. 상품 링크와 **원본 장면의 유튜브 타임스탬프**만 건다.

## 갱신

```
python -X utf8 scripts/수집.py daily     # 구독자 2채널 · MV 11편 조회수
python -X utf8 scripts/수집.py weekly    # 구글 트렌드 126주 · playboard 순위
python -X utf8 scripts/수집.py videos    # 채널 두 개 전편 조회수·좋아요 (10~20분)
python -X utf8 scripts/수집.py archive   # @data-viz 에 새로 올린 쇼츠를 카드로
python -X utf8 scripts/수집.py emoticon  # 카카오 이모티콘 인기 순위 여섯 탭
python -X utf8 scripts/수집.py club      # 걸그룹 100만 클럽 44팀 구독자
python -X utf8 scripts/수집.py daily --확인   # 아무것도 쓰지 않고 조회만
```

`videos` 는 가장 무겁다. **어느 탭(영상·쇼츠·라이브)에 있는 영상인가는 API 로 알 수 없어**
목록은 키가 있어도 yt-dlp 로 뽑고, 조회수·좋아요만 키가 있으면 API 로 받는다.
키가 없으면 편당 한 번씩 열어 보므로 리센느 공식 1,700편에 10분 넘게 걸린다.
**저장소에는 채널마다 조회수·좋아요 상위 150편(형식마다 80편)만 남긴다** —
전편을 매주 커밋하면 저장소가 주당 300KB 씩 분다. 화면의 누적 조회수·좋아요는
남긴 편이 아니라 **전편을 더한 값**이라 따로 담는다.

`YOUTUBE_API_KEY` 가 있으면 YouTube Data API v3 를, 없으면 yt-dlp 를 쓴다.
Actions IP 는 yt-dlp 봇 차단이 잦으니 워크플로에서는 저장소 secret 에 키를 넣는다.

처음 만들 때 쓴 변환 스크립트(`대시보드_데이터변환.py`)는 **이 저장소에 없다.**
작성자 로컬의 쇼츠 작업 폴더를 읽고, 화면에서 뺀 검색어 목록을 담고 있어 저장소 밖에 둔다.
data/ 를 채우는 일은 이제 `scripts/수집.py` 가 한다.

## 지킬 것

- **공개 저장소다.** `.gitignore` 를 먼저 확인하고 커밋한다. 전사 원문 · 화자배정 · 성문 프로필 ·
  얼굴 이미지 · 개인 신상은 어떤 경로로도 올리지 않는다.
- **API 키는 저장소 secret 에만.** 워크플로 YAML 에도 남기지 않는다.
- **구글 트렌드는 매주 전체를 교체한다.** 새 최고점이 나오면 지난 126주 값이 전부 재정규화돼
  내려간다. 마지막 점만 이어 붙이면 틀린 그림이 된다.
- **수집 실패는 덮어쓰지 않는다.** 성공했을 때만 JSON 을 쓰고 실패는 `status.json` 에 남긴다.
- **썸네일은 참조만 한다.** `i.ytimg.com` 을 그대로 쓰고 파일을 저장소에 복사하지 않는다.
  카드·줄 전체가 그 영상 링크가 되어야 유튜브 약관을 지킨다.

## 수집 주기

`collect.yml` 은 **매시 0분**에 돈다.

100만 돌파(2026-08-19) 전까지는 30분 간격이었다. 리센느 공개 구독자가 1,000명 계단이라
하루 17칸씩 올라 돌파 순간을 놓치지 않으려던 것이다. 넘은 뒤로는 그만큼 촘촘할 이유가 없다.
더 낮추려면 cron 을 `0 0 * * *` (매일 09:00 KST) 로 바꾼다.

GitHub 의 schedule 은 정시를 보장하지 않는다. 혼잡하면 5~15분, 드물게 그 이상 늦는다.

## 아직 안 한 것

- **새로 100만을 넘긴 걸그룹은 자동으로 들어오지 않는다.** `club.json` 에 채널 ID 가 들어가
  44팀 구독자는 주 1회 자동으로 갱신되지만, 수집기는 **목록에 있는 채널만 다시 잰다.**
  새 팀을 넣으려면 걸그룹 전수 조사를 다시 해야 하고 그건 수동이다.

  채널 ID 는 **유튜브 채널검색(`sp=EgIQAg`)으로 찾고 2026-08-17 실측 구독자와 ±25% 안에 드는
  후보만 채택했다**(44팀 전부 확정). **핸들을 추측하면 안 된다** — `@MAMAMOO_` · `@2NE1official`
  같은 그럴듯한 핸들이 전부 남의 채널이었다. 404 보다 이쪽이 위험하다. 조용히 틀린 값을 주기 때문이다.

- **영상 랭킹 수집은 Actions 에서 돌지 않는다.** `videos.yml` 은 `YOUTUBE_API_KEY` 가
  저장소 secret 에 있을 때만 움직이고, 없으면 아무것도 하지 않고 끝난다. yt-dlp 로 한 편씩
  여는 방식이라 Actions IP 로 수천 번 두드리면 봇 차단을 부른다. 키를 넣기 전까지는
  로컬에서 `python -X utf8 scripts/수집.py videos` 를 돌리고 `data/videos.json` 을 커밋한다.

- **라이브 아카이브(`streams.json`)는 자동으로 갱신되지 않는다.** 멤버 판별이 얼굴 검출·정렬·임베딩을
  거치는 로컬 작업이라(`_모델/yunet.onnx` · `_모델/sface.onnx`) 이 저장소 안에서 돌릴 수 없다.
  편수·조회수는 늘어나도 이 화면의 값은 2026-08-20 집계에 멈춰 있고, 화면 10 의 표에 「수동」으로 적혀 있다.
  **한 편씩의 조회수·좋아요 순위는 여기 두지 않았다** — 03 영상 랭킹에서 형식을 「라이브」로 고르면
  같은 것이 나오고 그쪽은 주 1회 자동으로 갱신된다. 두 곳에 두면 값이 서로 어긋난다.

- **브랜드평판 TOP 10 은 매월 초 발표라 수동이다.** brikorea 원표를 확인하고
  `data/reputation.json` 을 고친 뒤 커밋한다.
